# FinalMortgageCalculator2

A Streamlit-based Mortgage Payments Calculator that calculates monthly mortgage payments, total payments, and total interest based on home value, deposit, interest rate, and loan term. Built with Python, Streamlit, Pandas, and Matplotlib.

Mortgage Payment Calculator 2

Link to streamlit cloud hosting: https://finalmortgagecalculator-apeynb2cik35ducwq5ussm.streamlit.app

Overview

The Mortgage Payment Calculator is a web application built using Python and Streamlit. It helps users estimate their monthly mortgage payments, total payments over the loan term, and total interest payable based on the home value, deposit, interest rate, and loan term.

Features

Calculate monthly mortgage payments.
Calculate total payments over the loan term.
Calculate total interest payable.
Interactive inputs for home value, deposit, interest rate, and loan term.
Visualize mortgage payment information using charts.
Simple and user-friendly interface.
Technologies Used

Python
Streamlit
Pandas
Matplotlib
Installation and Setup

1. Clone the repository

Replace YOUR_GITHUB_REPOSITORY_URL with your GitHub repository URL.

git clone YOUR_GITHUB_REPOSITORY_URL
2. Navigate to the project folder

cd FinalMortgageCalculator
3. Create a virtual environment

python3 -m venv .venv
4. Activate the virtual environment

On macOS or Linux:

source .venv/bin/activate
5. Install the required packages

pip install -r requirements.txt
6. Run the application

streamlit run Mortgage_Calculator.py

Deployment

This application can be deployed using Streamlit Community Cloud. Connect your GitHub repository, select the main branch, and set Mortgage_Calculator.py as the main application file.
